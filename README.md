# Факторы преступности в регионах РФ — прототип приложения

Учебный прототип к НИРС: связь социально-экономических показателей регионов России с уровнем
зарегистрированной преступности (85 регионов, 2011–2022 гг.).

Данные (открытые):
- преступность — Генеральная прокуратура РФ, обработка проекта «Если быть точным» (tochno.st/datasets/crime);
- социально-экономические показатели — Росстат, обработка «Если быть точным» (tochno.st/datasets/regions_collection);
- доля населения с высшим образованием — Всероссийские переписи населения 2010 и 2020 гг.

Запуск: `pip install -r requirements.txt`, затем `streamlit run app/app.py`.

Прогнозы ориентировочные: модель показывает связь показателей, причинность она не доказывает.
