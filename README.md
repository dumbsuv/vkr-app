# Факторы преступности в регионах РФ — веб-приложение

Реализация методики регрессионного анализа влияния социально-экономических факторов на уровень
зарегистрированной преступности в регионах России (85 регионов, 2011–2022 гг.).

Данные (открытые):
- преступность — портал правовой статистики Генеральной прокуратуры РФ, обработка проекта «Если быть точным»
  (tochno.st/datasets/crime); кражи, грабежи и разбои — ЕМИСС, показатель 36225 (МВД России);
- социально-экономические показатели — Росстат, обработка «Если быть точным» (tochno.st/datasets/regions_collection);
- доля населения с высшим образованием — Всероссийские переписи населения 2010 и 2020 гг.

Два режима:
- «Для органов власти» — уровень и место региона, сравнение условий с типичными, сценарий «что, если»,
  подбор сценария в пределах полномочий региона (безработица и доля бедных), выводы для региона;
- «Для аналитика» — выбор вида преступлений, метода регрессии и параметров, способы проверки качества,
  сравнение методов и видов преступлений, влияние факторов.

Открыть в браузере: https://vkr-app-c7rkb9hctzw2uwdkrxb3jp.streamlit.app

Запуск на своём компьютере: `pip install -r requirements.txt`, затем `streamlit run app/app.py`.

Оценки ориентировочные: модель показывает связь показателей, причинность она не доказывает.
